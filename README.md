# Jeff Walsh — Software Engineer Portfolio

A responsive, single-page portfolio for **Jeffrey Chandler Walsh (Jeff Walsh)**, featuring a futuristic dark interface with violet and cyan accents.

## Preview

Open `index.html` in a browser, or enable GitHub Pages to publish it.

## Sections

- Hero introduction and contact calls to action
- About and engineering principles
- Technology toolkit
- Featured project showcase
- Experience and education timeline
- Contact and social links

## Run locally

No build tools are required.

1. Clone this repository.
2. Open `index.html` in your browser.

## Personalize before publishing

The page currently includes sample project descriptions and editable placeholders. Update these with verified details:

- Replace the sample projects with real work, repository links, and outcomes.
- Keep only technologies you have hands-on experience with.
- Add your actual email address, LinkedIn URL, and resume URL.
- Add real experience, education, and dates.

## Deploy with GitHub Pages

1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/(root)`, then save.
4. GitHub Pages will provide the public site URL when deployment completes.
